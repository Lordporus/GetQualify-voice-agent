Questions

The things people ask first

How is it about 20x cheaper than ElevenLabs?

The voice runs on Rumik silk TTS, which lands around ₹0.50 per thousand characters for quality comparable to premium vendors. ElevenLabs and similar stacks sit roughly twenty times higher for the same volume. Same human grade voice, a fraction of the bill, billed in rupees.

What does provider agnostic actually mean?

Three layers, each a registry of adapters: TTS, the LLM brain, and telephony. Rumik, Gemini and VoBiz through Dograh are live today. ElevenLabs, Sarvam, Claude, Twilio and Zoom are stubs that go live the moment you add their key. Swapping a vendor is a setting, not a rewrite, so you are never locked in.

Is it really multi tenant for an agency?

Yes. Every workspace is an isolated tenant with its own users, agents, numbers, branding and usage. Tenant isolation is enforced on every read and write, so one client can never see or touch another client's data. You resell from a single console.

Can it make and take real phone calls?

Real inbound and outbound telephony runs through Dograh using your VoBiz numbers. Outbound dialing is guarded behind an explicit confirm so a paid call is never placed by accident. You can inspect the active configuration, numbers, and workflow routing in the console.

How fast does the agent start talking?

First audio lands under two seconds with streaming synthesis. The result is a call that feels like a person picking up rather than a bot buffering, which is the difference between a customer staying on the line and hanging up.

What do I need to run it?

One portable folder and Node. Zero npm dependencies, no build step, no framework. Copy the folder, run the server, and the console plus the API are live. The live keys are already wired and the demo tenant is seeded on first boot.
